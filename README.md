# llm-basics

First steps with the Anthropic API — learning project for my transition into AI Engineering.

## Scripts

- **chat.py** — CLI chatbot with conversation history (stateless API + message array)
- **translator.py** — translates any input to German via system prompt, temperature=0
- **classifier.py** — classifies customer feedback into structured JSON (few-shot prompting + json parsing)

## Key concepts practiced

Message structure, system prompts, few-shot examples, structured output, temperature settings.
